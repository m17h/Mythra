# Bundled Fonts

Mythra bundles these UI fonts locally so packaged builds do not depend on Google Fonts at runtime:

- Audiowide Regular
- Inter Regular, Medium, SemiBold, Bold
- JetBrains Mono Regular, Medium, SemiBold
- Quicksand Medium, SemiBold, Bold

The files were sourced from Google Fonts and are distributed under the SIL Open Font License 1.1 or the license provided by the upstream font family on Google Fonts.
